# Current Project Overview / 当前项目总览

This document summarizes the current setting, progress, and next plan for
counterfactual conversation emulation. 
本文档总结当前的研究设定、已经完成的进展，以及下一步计划。

## 1. Current Setting / 当前设定

### 1.1 Research Question / 研究问题

项目的核心问题是：在历史医生-患者对话中，如果把医生最终写出的诊断和治疗计划替换成一个固定 medical AI agent 的回答，平均质量会变成什么样？

The core question is: for historical clinician-patient encounters, what would
the average quality have been if a fixed medical AI agent had generated the
final diagnosis and management plan instead of the clinician?

当前版本把每个 encounter 建模为一个 single-step contextual bandit，而不是完整多轮对话 MDP：

Current version treats each encounter as a single-step contextual bandit rather
than a full multi-turn dialogue MDP:

```text
Observe patient context X_i
final clinical action A_i
Observe or assign reward Y_i in [0, 1]
```

主要 estimand 是 agent policy value 和相对医生行为策略的 deployment effect：

The main estimand is the target agent policy value and the deployment effect
relative to the clinician behavior policy:

```text
V(pi_agent) = E_X E_{A ~ pi_agent(. | X)} [q(X, A)]
V(pi_b)     = E_X E_{A ~ pi_b(. | X)}     [q(X, A)]
Delta       = V(pi_agent) - V(pi_b)
```
policy value：先从真实数据分布里抽一个 context X，再让 policy pi 在这个 X 下选 action，最后看这个 action 的期望 reward。

### 1.2 Dataset Construction / 数据集构建

每条样本被整理成 paired evaluation 结构：

Each record is organized into a paired evaluation structure:

```text
{
  X_i: patient context available at time zero,
  A_i^b: clinician final diagnosis / assessment / management plan,
  A_i^agent: target agent answer generated from the same X_i,
  E_i: embedding or learned representation of the action,
  Y_i^b: reward for the clinician action,
  Y_i^agent: reward for the agent action, used for evaluation
}
```

其中 `X_i` 必须只包含 time-zero information，也就是在最终诊断或治疗计划之前可用的信息。`A_i^b` 是从医生笔记中抽取出来的最终 clinical action。`A_i^agent` 是把相同 `X_i` 输入固定 agent policy 后生成的回答。

Here `X_i` must contain only time-zero information, before the final diagnosis
or plan. `A_i^b` is the clinician final action extracted from the note.
`A_i^agent` is generated by applying the fixed target agent policy to the same
context.

实验中 `Y_i^agent` 是为了评估 estimator 的 bias 和 RMSE 而保留的 ground-truth target score；estimator 本身主要从 logged clinician tuples 学习和估计。

In experiments, `Y_i^agent` is retained as the ground-truth target score for
measuring bias and RMSE. The estimator itself is evaluated as an off-policy
estimator that primarily uses logged clinician tuples.

### 1.3 Dataset Types / 数据集类型

当前数据集分为两类。

The current datasets fall into two types.

**With expert scored / 有专家评分的数据集**

这类数据集本身包含人类专家或专业标注者对回答质量的评分，因此 reward 来自 expert annotation，而不是 LLM judge。当前主要包括：

These datasets already contain human expert or professional ratings, so the
reward comes from expert annotation rather than an LLM judge. Current examples
include:

- Ayers AskDocs: physician response vs ChatGPT response, with healthcare-professional quality and empathy ratings.
- CounselBench-Eval: therapist/human baseline vs logged LLM responders, with mental-health professional annotations.

**Without expert scored / 没有专家评分的数据集**

这类数据集提供 medical dialogue 和 clinician note，但没有现成的人类质量评分。因此 pipeline 会先构建 `X_i` 和 `A_i^b`，再让固定 agent 对同一个 `X_i` 生成 `A_i^agent`，最后用 LLM judge 对医生回答和 agent 回答分别打分。

These datasets provide medical dialogues and clinician notes but no direct
human quality score. The pipeline first constructs `X_i` and `A_i^b`, generates
`A_i^agent` using the fixed agent, and then uses an LLM judge to score both the
clinician and agent answers.


LLM judge 使用 rubric 维度对 `(X_i, A_i)` 打分，例如诊断/计划质量、reasoning、communication、safety 等，并把结果归一化到 `[0, 1]`。

The LLM judge scores `(X_i, A_i)` across rubric dimensions such as diagnosis and
management quality, reasoning, communication, and safety, then normalizes the
reward to `[0, 1]`.

### 1.4 Estimator Inputs, Outputs, and Goal / 估计器输入、输出和目标

Estimator 的输入包括：

Estimator inputs include:

- patient context `X_i`
- logged clinician action `A_i^b`
- generated target-agent action `A_i^agent`
- clinician reward `Y_i^b`
- text embeddings or learned features for context/action pairs

Estimator 的输出是：

Estimator output is:

```text
V_hat(pi_agent)
```

也就是目标 agent policy 的平均 reward 估计值。然后可以和医生行为策略的 empirical value 对比：

This is the estimated average reward of the target agent policy. It is compared
with the empirical clinician behavior value:

```text
V_hat(pi_b) = (1 / n) sum_i Y_i^b
Delta_hat   = V_hat(pi_agent) - V_hat(pi_b)
```

Estimator 的目标不是直接预测每个样本的 agent score，而是在 partial-feedback / off-policy setting 下尽可能准确地估计整体 policy value。

The estimator's goal is not merely to predict each individual agent score. It
is to estimate the overall policy value under a partial-feedback off-policy
setting.

### 1.5 Evaluation Metrics / 评估指标

因为实验数据中我们也有 `Y_i^agent`，所以可以计算 empirical ground truth：

Because experimental datasets also contain `Y_i^agent`, we can compute an
empirical ground truth:

```text
V_true(pi_agent) = (1 / n) sum_i Y_i^agent
```

Estimator 效果主要用以下指标判断：

Estimator quality is judged by:

- Bias: `V_hat(pi_agent) - V_true(pi_agent)`
- Relative bias: `Bias / V_true(pi_agent)`
- RMSE: bootstrap estimates against `V_true(pi_agent)`
- Direction agreement: whether `V_hat(pi_agent) - V_hat(pi_b)` has the same sign as the true effect
- CI coverage: whether the confidence interval covers `V_true(pi_agent)`
- CI width: whether the interval is informative rather than too wide to use

## 2. Estimators / 估计器

### 2.1 Shared Features and Density Ratio / 共同特征和密度比

当前 real-data runner 会先分别 embed context 和 action：

The current real-data runner embeds context and action separately:

```text
phi_x              = embed(X_i)
phi_a_clinician    = embed(A_i^b)
phi_a_agent        = embed(A_i^agent)
```

然后构建交互特征：

It then builds interaction features:

```text
z_i(a) = [phi_x ; phi_a ; phi_x * phi_a]
```

Density ratio `w_i` 在 embedding feature space 中估计。实现上使用 classifier 区分 target-agent features `z_i(A_i^agent)` 和 behavior-clinician features `z_i(A_i^b)`，再把 classifier probability 转换成 target/behavior ratio。

The density ratio `w_i` is estimated in the embedding feature space. In
implementation, a classifier distinguishes target-agent features
`z_i(A_i^agent)` from behavior-clinician features `z_i(A_i^b)`, and classifier
probabilities are converted into a target/behavior density ratio.

```text
w_i ~= p(z_i(A_i^b) under pi_agent) / p(z_i(A_i^b) under pi_b)
```

### 2.2 Direct Method (DM)

DM 先用 logged clinician tuples 训练 reward model：

DM first trains a reward model on logged clinician tuples:

```text
q_hat(X_i, A_i^b) -> Y_i^b
```

然后直接在 agent action 上预测 reward：

It then predicts the reward for agent actions:

```text
V_hat_DM = (1 / n) sum_i q_hat(X_i, A_i^agent)
```

优点是稳定、低方差；缺点是如果 `q_hat` extrapolate 到 agent actions 时有系统性偏差，DM 会系统性低估或高估。

DM is stable and low-variance, but it can be systematically biased when
`q_hat` extrapolates poorly from clinician actions to agent actions.

### 2.3 Marginalized IPS / Self-Normalized MIPS

MIPS 用 embedding-space density ratio 给 logged clinician reward 加权。当前 headline 实现使用 self-normalized version，也就是 SNIPS：

MIPS weights logged clinician rewards by an embedding-space density ratio. The
current headline implementation uses the self-normalized version, SNIPS:

```text
V_hat_MIPS = sum_i w_i Y_i^b / sum_i w_i
```

其中 `w_i` 衡量 clinician action feature 在 target agent distribution 下相对于 behavior clinician distribution 的密度比。

Here `w_i` measures how likely the logged clinician action feature is under the
target agent distribution relative to the behavior clinician distribution.

为了得到 `w_i`，首先需要 训练一个二分类器区分 `D = 1: sample 来自 agent policy` 或者是 `D = 0: sample 来自 clinician / behavior policy`

然后再使用
```text
p_i = P_hat(D = 1 | Z_i^b)
```
P_i 就是对于这个真实 clinician action 的 embedding feature，分类器认为它有多像 agent policy 产生的 action，最后得到 `w_i` importance weight
```text
w_i = p_i / (1 - p_i)
```

MIPS 的优点是可以不训练 reward model；缺点是高度依赖 embedding support 和 density-ratio 估计，weight tail 会导致 CI 很宽。

MIPS avoids direct reward modeling, but it depends strongly on embedding
support and density-ratio quality. Heavy weight tails can make uncertainty
intervals very wide.

### 2.4 OffCEM

OffCEM 结合 reward model 和 density-ratio correction。当前 real-data 实现对 residual correction 使用 self-normalization：

OffCEM combines a reward model with a density-ratio residual correction. The
current real-data implementation self-normalizes the residual correction:

```text
residual_i = Y_i^b - q_hat(X_i, A_i^b)

V_hat_OffCEM =
  (1 / n) sum_i q_hat(X_i, A_i^agent)
  + sum_i w_i residual_i / sum_i w_i
```

直觉上，DM term 给出 agent action 的 reward prediction，weighted residual correction 用 clinician logged data 修正 reward model 的偏差。

Intuitively, the DM term predicts reward for agent actions, while the weighted
residual correction uses logged clinician data to correct reward-model bias.


### 2.5 Marginalized Doubly Robust (MDR)

MDR 是最近加入的探索性 estimator。它使用标准 unnormalized doubly robust correction：

MDR is the recently added exploratory estimator. It uses the standard
unnormalized doubly robust correction:

```text
V_hat_MDR =
  (1 / n) sum_i [
    q_hat(X_i, A_i^agent)
    + w_i * (Y_i^b - q_hat(X_i, A_i^b))
  ]
```

它和当前 OffCEM 的关键区别是 residual correction 不做 self-normalization：

Its key difference from the current OffCEM implementation is that the residual
correction is not self-normalized:

```text
OffCEM correction = sum_i w_i residual_i / sum_i w_i
MDR correction    = (1 / n) sum_i w_i residual_i
```

最新五数据集对比显示，MDR 没有超过之前最优的 DM/MIPS/OffCEM cell，因此目前更适合作为 negative/exploratory result 和 DR correction 形式诊断。

The latest five-dataset comparison shows that MDR does not beat the previous
best DM/MIPS/OffCEM cell. It is therefore best treated as a
negative/exploratory result and a diagnostic for DR correction design.

## 3. Current Best Embedding Setup / 当前最强嵌入设定

当前最强 point-estimation 设定是：

The strongest current point-estimation setup is:

```text
BGE-M3 + learned concat-PCA + MIPS
```

流程如下：

The workflow is:

```text
1. Use BGE-M3 to embed X_i, A_i^b, and A_i^agent.
2. Train a reward-informed learned projection on clinician tuples only:
   (phi_x, phi_a_clinician) -> Y_i^b.
3. Use concat-PCA merge:
   z = [PCA(phi_base) ; learned_projection(phi_base)].
4. Build estimator features [z_x ; z_a ; z_x * z_a].
```

这个 learned projection 只使用 clinician reward `Y_i^b` 训练，不使用 agent reward `Y_i^agent`。`Y_i^agent` 只在最终 evaluation 时用于计算 true value、bias 和 RMSE。

The learned projection is trained only with clinician reward `Y_i^b`; it does
not use agent reward `Y_i^agent`. Agent reward is used only at final evaluation
time to compute true value, bias, and RMSE.

这个设定的优势是：PCA block 保留 BGE-M3 的原始语义几何，learned block 增加 reward-informed correction，因此比单纯 frozen embedding 更适合当前 reward-estimation/OPE 任务。

This setup keeps the original BGE-M3 semantic geometry through the PCA block
while adding a reward-informed correction through the learned block, making it
stronger than a purely frozen embedding for the current OPE task.

## 5. Plan / 下一步计划

### 5.1 Core Problem / 当前最想解决的问题

当前最核心的问题是 estimator 能力还不够强。即使最好的 point-estimation setup 已经明显优于早期 baseline，很多结果仍然系统性低估 `V(pi_agent)`，并且 plain bootstrap CI 覆盖不足。

The central current problem is estimator strength. Even though the best
point-estimation setup is clearly better than earlier baselines, many results
still systematically underestimate `V(pi_agent)`, and plain bootstrap
intervals often fail to cover truth.

因此下一阶段的重点不是单纯继续扩数据集，而是优化 estimator。

Therefore, the next phase should focus on estimator improvement rather than
only expanding datasets.

### 5.2 Estimator Optimization Directions / 估计器优化方向

下一步优先方向：

Priority directions:

- Improve density-ratio estimation and positivity diagnostics: inspect weight tails, effective sample size, support mismatch, and calibration.
- Improve the reward model `q_hat`: reduce extrapolation bias from clinician actions to agent actions.
- Explore more stable doubly robust estimators: keep the residual correction useful without letting weights dominate.
- Keep MIPS/SNIPS as the point-estimate baseline because it currently has the strongest RMSE in many cells.
- Keep OffCEM plus conformal CI as the uncertainty-aware reporting route because it gives more usable confidence intervals.
- Treat MDR as an exploratory negative result that motivates better DR correction design.
